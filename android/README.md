# Sofia Android prototype

Начальный нативный Android-модуль для испытания фонового голосового режима.

## Уже заложено
- Опциональный NotificationListenerService для входящих уведомлений, классифицированных Android как сообщения; включается пользователем в системных настройках доступа к уведомлениям.
- Передача текста входящего сообщения в Cloudflare Worker `/api/translate`: русский текст сохраняется, корейский и другие языки переводятся на русский, затем результат ставится в очередь голосового чтения.
- Текст уведомлений не записывается в локальную историю приложения; при ошибке перевода оригинал не зачитывается вместо перевода.
- Foreground Service с типом microphone и постоянным уведомлением.
- Разрешения Android на микрофон и уведомления.
- Повторный запуск системного распознавания русской речи после завершения каждой фразы.
- Кодовое слово «София», затем приём следующей команды.
- Отправка команды на существующий Cloudflare Worker и озвучивание ответа через Android TextToSpeech.

## Важно перед реальным использованием
Серверный маршрут `/api/translate` добавлен в эту рабочую ветку и покрыт автоматическими тестами, но его развёртывание в активный Cloudflare Worker отдельно не подтверждено. Пока Worker не обновлён, приложение не сможет получить реальный перевод с сервера. Android CI собирает APK, но не публикует Worker.

## Настройка чтения сообщений
1. Запусти Софию и нажми «Разрешить Софии читать сообщения».
2. В системном списке доступа к уведомлениям включи Софию.
3. Оставь голосовой режим активным, чтобы служба могла зачитывать новые сообщения.
4. Android передаёт только содержимое, доступное в уведомлении. История переписки и скрытый текст недоступны через этот механизм.

Сейчас обрабатываются уведомления, которые Android помечает как сообщения (категория `msg`) или которые используют MessagingStyle. Доступ к тексту отправляется на сервер перевода только после явного включения Notification Access.

## Ограничения
- Это ранний прототип, не low-power hotword engine и не голосовая биометрия.
- Используется Android SpeechRecognizer. Локальный распознаватель выбирается, только если устройство сообщает о его доступности; иначе системный сервис может использовать сеть.
- Циклическое распознавание может прерываться прошивкой, энергосбережением или отсутствием сети. Для надёжного постоянного wake word нужен отдельный локальный движок.
- Android требует разрешения пользователя и запуска микрофонной foreground-службы из видимой Activity. Пока служба активна, будет видно постоянное уведомление.
- Это исходники, не готовый APK. Gradle Wrapper пока не добавлен, сборка на реальном Samsung ещё не проверена.

## Сборка
Открой папку android в Android Studio, синхронизируй Gradle и собери debug APK. Проверь работу на реальном устройстве.
