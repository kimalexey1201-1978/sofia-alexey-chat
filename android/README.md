# Sofia Android prototype

Начальный нативный Android-модуль для испытания фонового голосового режима.

## Уже заложено
- Foreground Service с типом microphone и постоянным уведомлением.
- Разрешения Android на микрофон и уведомления.
- Повторный запуск системного распознавания русской речи после завершения каждой фразы.
- Кодовое слово «София», затем приём следующей команды.
- Отправка команды на существующий Cloudflare Worker и озвучивание ответа через Android TextToSpeech.

## Ограничения
- Это ранний прототип, не low-power hotword engine и не голосовая биометрия.
- Используется Android SpeechRecognizer. Локальный распознаватель выбирается, только если устройство сообщает о его доступности; иначе системный сервис может использовать сеть.
- Циклическое распознавание может прерываться прошивкой, энергосбережением или отсутствием сети. Для надёжного постоянного wake word нужен отдельный локальный движок.
- Android требует разрешения пользователя и запуска микрофонной foreground-службы из видимой Activity. Пока служба активна, будет видно постоянное уведомление.
- Это исходники, не готовый APK. Gradle Wrapper пока не добавлен, сборка на реальном Samsung ещё не проверена.

## Сборка
Открой папку android в Android Studio, синхронизируй Gradle и собери debug APK. Проверь работу на реальном устройстве.
