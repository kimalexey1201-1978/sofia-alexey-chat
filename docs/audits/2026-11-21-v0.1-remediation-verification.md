# Sofia Core v0.1 — Remediation and Verification Record

**Date:** 2026-11-21  
**Scope:** development branch `core/v0.1-minimal-cycle` only  
**Production status:** unchanged; no deployment performed.

## 1. Confirmed defects corrected

- The server-owned `SYSTEM_INSTRUCTION` in `src/worker/chat-route.mjs` still used the stale form of address `дорогой`. It now instructs Sofia to address the owner as `любимый` and not use his name.
- The browser compatibility prompt in `index.html` contained the same stale instruction. It has been aligned with the server instruction.
- The initial local greeting in `index.html` used `дорогой`; it now uses `любимый`.
- The profile label and exported transcript speaker label used the owner's name. They now use the neutral label `Ты`.
- A regression assertion was added to `tests/worker/chat-route.test.mjs` to ensure the trusted server instruction contains the approved form and excludes the stale forms.

## 2. Behaviors inspected and intentionally retained

- The browser sends its legacy first system message for compatibility. The Worker discards that untrusted message and supplies its own server-controlled instruction. This is the documented trust boundary, not a prompt-injection defect.
- The recent conversation history is intentionally forwarded as untrusted user/assistant context, with bounded count and content limits in Core. The inspected code does not support the earlier claim that conversation history was accidentally sent to the model.
- Chat bubbles use DOM `textContent` rather than interpreting model output as HTML. This is a safe rendering choice, not a functional defect. Markdown rendering remains a possible UI enhancement, not a verified cause of the reported issue.
- Retry uses a captured request snapshot; the existing tests cover retry snapshot stability and avoid duplicating the pending user message.

## 3. Platform limitation / blocker

The inspected repository contains the HTML/JavaScript chat prototype, Cloudflare Worker, Core modules, contracts and tests. It does not contain an Android Gradle project, Android manifest, Kotlin/Java application sources, or an APK build configuration. Therefore Android-native UI, microphone lifecycle, permissions, Android media/gallery access, and APK behavior cannot be corrected or verified from this repository. No Android changes are claimed.

## 4. Known boundaries not changed in this milestone

- The current Worker route is an inference-only chat endpoint. The readiness documentation explicitly excludes authenticated owner identity, durable server-side conversation storage, device runtime, native Android integration and autonomous actions from this slice.
- CORS is a browser cross-origin policy and is not owner authentication.
- The branch `core/v0.1-minimal-cycle` is materially divergent from `main` (444 commits ahead and 4 behind at the time of audit). It was not merged into `main`; no attempt was made to reconcile the unrelated branch histories.
- Cloudflare deployment, production environment variables, secrets and the production branch were not modified.
